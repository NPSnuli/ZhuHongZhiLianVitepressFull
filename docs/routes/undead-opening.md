# 亡灵如何开局

1.  开局你在帕拉汶出生，那么你就去拿帕拉汶的箱子（手半剑和剑，一把自己用一把给NA/NC），然后直接北上去提哈拿武士长刀和头盔；之后最短距离去日瓦车则拿畸形甲（短刀放背包里不用）；然后穿上盔甲头盔拿起长刀，直接挑最近的村子烧村（不是去真烧，而是镇压农民刷阿修罗，刷法去萌新攻略里面看），刷出来就走，然后接下来开始你的宏图霸业

2.  我知道开局缺兵但是一定要发育母体（三神十天降级一次很爽），缺兵找辣条或者烧村（看看村子里的维吉亚神殿卫士多么好），辣条可以感染可以不感染（最好装备是豪华银甲套），亡灵的母体发育起来就很好打了

3.  建议亡灵称号：地狱使者、嗜血魔王、阿修罗、五印（剩下的随心）

4.  重要的一点：亡灵可以点几点掠夺（掠夺上限为15，最高点到9因为你有霸者强权），保证永远不缺钱（升级要钱，早期玩家缺钱的要死）

5.  五印刷的方法：海贼系列（有手就行）——绿林系列（当下弓箭手ai加强导致绿林的智商更高，请认真考虑一下）——马贼系列——山贼和沙漠系列
