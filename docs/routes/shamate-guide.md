关于杀马特怎么使用：

1.  杀马特，作为朱红最长的武器，也是第二实用的步战武器（第一是杀马特·云戈），能力出众，伤害不俗，但由于过长的攻击范围导致卡刀简直就是家常便饭，而卡刀频繁与否决定会玩杀马特与否

2.  卡刀问题：400攻击距离其实说穿了也就大概四五个身位的距离，卡好这个点就需要点的主要技能就是敏捷＋步战，武器掌握和强击补充伤害，你要做到跑得比海盗头目还快，那你就能单刷海盗头目了、

3.  乱杀各种兵种的基础：

    步兵：你跑的比他快（最简单）

    射手：秘技·反复横跳掌握好，同时跑的要快免得他以你为圆心后退你不好整（射手可以利用一个攻击力不高的比如绿林盗贼、雪原盗贼等当挡箭牌去接近其他人）

    骑兵：这个比较难，要卡好身位，带上不同的武器（标枪\近战武器）在距离近时换武器，同时如果只有大概三个身位可以考虑戳马腿站着的地面，一样有奇效，或者直接跳起来刺防骑兵冲撞与大量骑兵蜂拥

    骑射手：这个的话........还是买几个盾牌让他把箭射完好办（龙骑兵之盾好评）

4.  杀马特额外提示：
