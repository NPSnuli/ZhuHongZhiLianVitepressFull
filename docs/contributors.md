## 如何添加贡献者

直接编辑本页的表格即可。推荐写清楚三点：

1. 贡献者昵称或团队名。
2. 具体贡献，不要只写“感谢”。
3. 是否允许放链接；不确定时只写昵称和贡献说明。

示例：

```md
| 路线攻略 | 某某 | 补充亡灵开局路线、修正第 3 步触发条件 | 论坛帖 / B站 / 群昵称 |
```

## 待确认事项

- 原 Word 文档里的作者署名是否需要逐篇搬到对应攻略页。
- 外部论坛、群聊、视频链接是否需要加到右下角攻略入口。
- 是否需要按版本建立“贡献记录 / 更新日志”。
